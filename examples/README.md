# Example: tank-farm piping plan

`tank_farm.dxf` is a small but realistic plan (units mm) generated by `make_example.py`:

- three storage tanks in a bund (dike) with rounded corners; the bund floor is a hatch with the tank
  footprints as holes, the bund wall a closed polyline with bulge corners;
- product lines DN200 and DN150 with long-radius bends (polyline bulges), cooling water DN100/DN50,
  an open fire water ring main and a drain channel drawn as a spline;
- a pump room (outline + floor hatch) with three pumps;
- valves as blocks with `TAG` and `SIZE` attributes; the butterfly valves are a dynamic block stored
  as anonymous `*U` blocks, as AutoCAD does;
- nine pipe supports as one MINSERT array, hydrants, and an abandoned route on a frozen layer.

`takeoff.toml` prices it: 18 BOQ items for pipes, valves and civil works. The rates are
illustrative only.

```bash
dxf-takeoff examples/tank_farm.dxf --out-units m --group-by-attrib SIZE --rules examples/takeoff.toml
```

Committed outputs of that command: [`takeoff.xlsx`](takeoff.xlsx), [`takeoff.json`](takeoff.json),
[`csv/`](csv/) and the terminal output in [`../docs/example-output.md`](../docs/example-output.md).

`make_example.py` also computes the main quantities by hand (pipe lengths with bends, bund wall
length, bund floor area, ring main length); `tests/test_example.py` checks that dxf-takeoff agrees.

Regenerate everything with:

```bash
python examples/make_example.py
python examples/make_outputs.py
python examples/make_screenshot.py   # needs matplotlib: pip install "dxf-takeoff[docs]"
```
